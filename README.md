# Análise e Segmentação de Clientes em Varejo Online

###  Ideia do Projeto

o objetivo do projeto foi usar os dados do Excel para criar um banco de dados e me preparei para as análises.

###  Minha Jornada (Passo a Passo)

1.  **iniciei limpando os dados.** Em seguida, limpei os dados, removendo os clientes sem ID e as devoluções.
2.  **Criei as "notas" dos clientes.** Para entender cada cliente,  dei uma 'nota' para eles: a **Recência** (há quanto tempo ele comprou), a **Frequência** (quantas vezes ele comprou) e a **Monetariedade** (o total que ele gastou).
3.  **Agrupei os clientes.** Por fim, usei machine learning para encontrar 4 grupos de clientes. Foi muito legal, porque o programa me mostrou quem são os clientes 'VIPs' e quem são os clientes que 'pararam de comprar'.



4.  🛠️ Ferramentas e Tecnologias
Linguagem de Programação: Python

Linguagem de Consulta: SQL

Bibliotecas: pandas (para manipulação de dados), sqlite3 (para o banco de dados), scikit-learn (para o machine learning), matplotlib (para a visualização do gráfico do cotovelo), datetime (para trabalhar com as datas).
